This Website?

What is it?

This website is something I have been meaning to make for a while. A place to showcase my skills and all of my work. But procrastination ran its course... I needed to create a website portfolio for my GIS class. (check out more here) and instead of making it in Google sites, this is what you get.

Nerd-Specs:

This website is a FastAPI server using Jinja2 templates running using docker compose on my homelab (shameless plug?)" in a Debian virtual machine.

MATES Reflection

Why FastAPI instead of something else?

FastAPI is a dynamic web framework to build APIs and backend services in Python. It is used for APIs, services, and web apps. I use FastAPI for my websites as it was easiest to learn (what was recommended to me). FastAPI has built in API documentation with async/awaits, data validation with Pydantic.

Why host it myself?

If you really think about it, there is no reason to self-host...oh wait yes there is. Hosting on my own server gives me full freedom as well as full responibility. I control what data gets put on the internet and update it as well. I also get to save costs on cloud hosting while hosting on my own domain.
